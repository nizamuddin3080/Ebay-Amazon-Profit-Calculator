# Project Guidelines & Rules

## Git & Version Control
- **Always commit and push changes to Git**:
  - Remote: `https://github.com/nizamuddin3080/Ebay-Amazon-Profit-Calculator.git`
  - Target Branch: `main`
- Keep commits clear, descriptive, and atomic.
- After implementing features, fixing bugs, or updating files, stage the changes, commit them, and push to `origin main`.
